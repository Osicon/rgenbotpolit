1. Introducción

Esta Política de Privacidad explica cómo Rgen trata la información relacionada con el uso del bot dentro de Discord. Rgen es un bot de uso general que, según la información facilitada por su desarrollador, se ejecuta en una computadora y no utiliza una base de datos persistente para guardar información de los usuarios. Esta descripción debe verificarse antes de publicar la política.

2. Información que puede procesar Rgen

Para funcionar, Rgen puede recibir o procesar temporalmente información proporcionada a través de Discord, según los comandos, permisos e interacciones que utilicen los usuarios. Esto podría incluir:

  • Identificadores de usuarios, servidores y canales necesarios para ejecutar determinados comandos.
  • El contenido de los comandos o interacciones enviados al bot.
  • Información básica que Discord proporciona al bot según los permisos y funciones habilitados.
  • Información técnica necesaria para ejecutar comandos y responder a solicitudes.

Esta lista describe tipos de información que pueden ser procesados, no una afirmación de que Rgen recopile todos esos datos. La recepción o el procesamiento temporal no significa necesariamente que la información se almacene de forma permanente. Rgen no debe solicitar contraseñas de Discord, tokens personales de acceso ni otras credenciales privadas de los usuarios.

3. Almacenamiento de información

Según la información facilitada por el desarrollador, Rgen no utiliza una base de datos persistente para guardar información de los usuarios. El bot se ejecuta en una computadora y puede mantener información temporal en memoria para procesar comandos y realizar sus funciones.

Pendiente de confirmar: esta declaración presupone que el código, las bibliotecas, los archivos de configuración y el entorno de ejecución no guardan información personal en archivos, registros, historiales, cachés u otros sistemas persistentes. Si se habilitan registros técnicos, archivos de datos, bases de datos o almacenamiento externo, esta sección deberá actualizarse para describirlos.

4. Finalidad del procesamiento

La información que Rgen procese se utiliza en la medida necesaria para ejecutar los comandos solicitados, responder a las interacciones, proporcionar las funciones habilitadas y mantener el funcionamiento técnico del servicio cuando corresponda. Las finalidades reales deben coincidir con las funciones que estén implementadas.

5. Compartición de información

Según la información disponible, no se ha declarado el uso de una base de datos externa ni de un servicio de almacenamiento externo por parte de Rgen. El bot se comunica con Discord para funcionar; el tratamiento de información que Discord realiza en sus propios servicios está sujeto a las políticas de privacidad de Discord.

Pendiente de confirmar: si el código utiliza servicios de inteligencia artificial, APIs externas, sistemas de registro, servicios de alojamiento remoto u otros proveedores que reciban información, deberán identificarse aquí y explicarse las categorías de datos que reciben. No debe interpretarse esta sección como una garantía de que ningún tercero procesa información durante el funcionamiento del bot.

6. Conservación y eliminación de datos

De acuerdo con la configuración declarada, Rgen no mantiene una base de datos persistente de información de usuarios. La información procesada temporalmente se utiliza durante la ejecución de las funciones correspondientes. No se declara un periodo de conservación de datos almacenados porque, según la información disponible, no existe dicho almacenamiento persistente.

Si se descubre que se conservan datos en registros, archivos o sistemas externos, esta sección deberá especificar qué se conserva, durante cuánto tiempo y cómo se elimina.

7. Seguridad

El responsable debe tomar medidas razonables para proteger el código, las credenciales del bot y la computadora donde se ejecuta Rgen. Los tokens y las credenciales deben mantenerse privados y no publicarse en repositorios, mensajes o archivos accesibles al público. Ningún sistema informático puede garantizar una seguridad absoluta.

8. Solicitudes de los usuarios

Los usuarios pueden contactar al responsable para formular preguntas sobre el tratamiento de su información o solicitar la eliminación de datos que Rgen conserve, cuando corresponda. Para presentar una solicitud, utiliza el medio de contacto indicado al final de esta política. Las solicitudes se atenderán conforme a la normativa aplicable y a las limitaciones técnicas pertinentes.

9. Menores de edad

El uso de Rgen está sujeto a los requisitos de edad aplicables y a las condiciones y políticas de Discord. Rgen no está destinado a eludir las restricciones de edad de Discord ni las medidas de protección aplicables.

10. Cambios en esta política

Esta política podrá actualizarse si cambian las funciones de Rgen, los datos que procesa, el modo de alojamiento o las prácticas de almacenamiento. La versión vigente estará disponible en esta página.
